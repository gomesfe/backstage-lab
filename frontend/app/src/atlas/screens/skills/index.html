Skill do agente

Buscar no catálogo

buscar_catalogo·ativaleitura

Encontra aplicações, APIs, sistemas, recursos de nuvem, squads e ofertas de provisionamento. Responde o que existe, de quem é e qual oferta usar. Devolve até 15 resultados com o link de cada um.

Parâmetros

texto
Termo procurado no nome, título, descrição e tags. Sem texto, lista tudo do tipo.
tipo
Component, API, System, Resource, Group ou Template (oferta).
dono
Grupo dono, ex.: pagamentos.

Exemplos de pergunta

  • Quais filas SQS o time de pagamentos tem?
  • Qual oferta eu uso para criar um bucket S3?
  • Quais APIs estão em produção?

Fonte: Catálogo. O agente usa as permissões de quem está conversando.

Detalhar uma entidade

detalhar_entidade·ativaleitura

Traz os detalhes de uma entidade do catálogo a partir da referência: descrição, dono, ciclo de vida, sistema, tags, relações e o link no portal.

Parâmetros

ref *
Referência da entidade no formato kind:namespace/nome, ex.: component:default/pagamentos-api.

Exemplos de pergunta

  • Me fala da API pagamentos-api: dono, ciclo de vida e sistema.
  • Do que depende o sistema de pagamentos?

Fonte: Catálogo. O agente usa as permissões de quem está conversando.
