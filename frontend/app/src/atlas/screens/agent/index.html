Quais ofertas existem para criar um banco de dados?
🔍 Buscou ofertas no catálogo

Há quatro ofertas de banco de dados em Ofertas:

  • Banco relacional RDS — PostgreSQL ou MySQL gerenciado.
  • Aurora Serverless v2 — escala sozinho, bom para carga variável.
  • Aurora com capacidade provisionada — carga estável e previsível.
  • Tabela DynamoDB — chave-valor, sem servidor.

Todas abrem um PR no repositório de infraestrutura; nada é aplicado direto.
